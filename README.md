# DOT LAB

点・動き・触れる仕掛けで遊ぶ、静的なポートフォリオ／モーション実験サイトです。

## 内容

- 起動画面、ホーム、作品一覧、ブラウザゲーム
- 14項目のモーション周期表、10習作の緩急強調版／元の版
- 緩急のものさし：点とベジェハンドルを直接動かす値グラフ、比較再生、Undo
- DOT MIX、FOUR EDGES、視点・向き・注意の実験

## ローカルで開く

ビルドや依存パッケージは不要です。Python 3 がある環境でリポジトリのフォルダーを開きます。

```sh
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:8000/ を開きます。緩急エディターは `dist/motion-timing.html#touch-workbench` です。

## GitHub Pages

リポジトリ公開後、Settings → Pages で公開するブランチと `/ (root)` を選択します。ルートの `index.html` が `dist/` に案内します。プロジェクトサイトでも相対リンクを使います。パッケージを用意しただけでは公開や設定変更は実行されません。

## 操作と制約

グラフの点を動かすと、その時刻の位置がプレビューに反映されます。白いハンドルで曲線を調整し、離すと一度だけ試走します。数値・矢印キー操作、Undo、元のリズムへ戻す操作もあります。試走はOFFにできます。

編集内容はメモリ上だけです。再読み込みやプリセット切替で消えます。アカウント、保存サーバー、AI APIは含みません。ホームの案内はローカルの定型ガイドです。別の非公開サイトを必要としないよう習作を同梱しました。

## テスト

Python 3 と Node.js を使用。外部パッケージのインストールは不要です。

```sh
python tests/check-static.py
node tests/run-all.cjs
```

数値計算、DOMシミュレーション、状態遷移、ローカルリンク、JavaScript構文を確認します。実端末のアクセシビリティ認証や実機動作保証ではありません。
